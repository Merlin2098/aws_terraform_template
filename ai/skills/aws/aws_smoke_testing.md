# AWS Smoke Testing Pattern

## When to use

- After deploying AWS infrastructure in a host repository
- Before running production workloads
- As part of pre-deployment validation (SPEC-009 §4)

## Core idea

Every host repository that deploys AWS resources must include operational
validation scripts under `tests/aws/`. These scripts are generated by the
agent when infrastructure is created — they are not part of the template itself.

## Directory structure to generate in the host

```
tests/aws/
├── precheck/
│   ├── validate_iam.ps1        # IAM role + trust policy + policy attachments
│   ├── validate_tags.ps1       # Mandatory tags on all resources
│   ├── validate_budget.ps1     # Budget existence check
│   └── smoke_resources.ps1     # S3, IAM role, CloudWatch log group existence
│
├── smoke/
│   ├── smoke_s3.ps1            # Bucket exists and is accessible
│   ├── smoke_cloudwatch.ps1    # Log group exists and retention is configured
│   └── smoke_iam.ps1           # Role is assumable by the declared service
│
├── logs/
│   ├── download_cloudwatch_logs.ps1   # Download log streams to logs/
│   └── export_pipeline_outputs.ps1   # terraform output -json → logs/tf_outputs.json
│
├── gitbash/
│   └── precheck.sh             # Bash equivalent of precheck scripts (CI/Linux)
│
└── README.md
```

## Script templates

### validate_iam.ps1

```powershell
param(
  [string]$RoleName   = $env:TF_VAR_execution_role_name ?? "data-job-execution-role",
  [string]$Project    = $env:TF_VAR_project_name ?? "data-platform",
  [string]$Env        = $env:TF_VAR_environment ?? "dev"
)

$prefix = "$($Project.ToLower())-$($Env.ToLower())"
$fullRoleName = "$prefix-$RoleName"

Write-Host "Validating IAM role: $fullRoleName"
$role = aws iam get-role --role-name $fullRoleName | ConvertFrom-Json

if (-not $role) { Write-Error "Role not found: $fullRoleName"; exit 1 }

$trust = $role.Role.AssumeRolePolicyDocument | ConvertFrom-Json
$services = $trust.Statement.Principal.Service
Write-Host "Trust services: $services"

$policies = aws iam list-attached-role-policies --role-name $fullRoleName | ConvertFrom-Json
Write-Host "Attached policies: $($policies.AttachedPolicies.PolicyName -join ', ')"
Write-Host "IAM validation passed."
```

### validate_tags.ps1

```powershell
param(
  [string]$Project = $env:TF_VAR_project_name ?? "data-platform",
  [string]$Region  = $env:AWS_DEFAULT_REGION ?? "us-east-1"
)

$required = @("Project", "Environment", "Owner", "ManagedBy", "CostCenter")
$resources = aws resourcegroupstaggingapi get-resources `
  --tag-filters "Key=Project,Values=$Project" `
  --region $Region | ConvertFrom-Json

foreach ($r in $resources.ResourceTagMappingList) {
  $tagKeys = $r.Tags | ForEach-Object { $_.Key }
  $missing = $required | Where-Object { $_ -notin $tagKeys }
  if ($missing) {
    Write-Warning "$($r.ResourceARN) missing tags: $($missing -join ', ')"
  }
}
Write-Host "Tag validation complete."
```

### validate_budget.ps1

```powershell
param([string]$AccountId = (aws sts get-caller-identity | ConvertFrom-Json).Account)

$budgets = aws budgets describe-budgets --account-id $AccountId | ConvertFrom-Json
if ($budgets.Budgets.Count -eq 0) {
  Write-Error "No AWS Budgets found. Deploy infra first."; exit 1
}
Write-Host "Budgets found: $($budgets.Budgets.BudgetName -join ', ')"
```

### smoke_resources.ps1

```powershell
param(
  [string]$Project = $env:TF_VAR_project_name ?? "data-platform",
  [string]$Env     = $env:TF_VAR_environment ?? "dev",
  [string]$Region  = $env:AWS_DEFAULT_REGION ?? "us-east-1"
)

$outputs = terraform -chdir=infra output -json | ConvertFrom-Json

# S3
$bucket = $outputs.artifact_bucket_name.value
aws s3 ls "s3://$bucket" | Out-Null
if ($LASTEXITCODE -ne 0) { Write-Error "S3 bucket not accessible: $bucket"; exit 1 }
Write-Host "S3 OK: $bucket"

# IAM role
$roleArn = $outputs.data_job_execution_role_arn.value
Write-Host "IAM role OK: $roleArn"

# CloudWatch log group
$logGroup = $outputs.log_group_name.value
aws logs describe-log-groups --log-group-name-prefix $logGroup --region $Region | Out-Null
if ($LASTEXITCODE -ne 0) { Write-Error "Log group not found: $logGroup"; exit 1 }
Write-Host "CloudWatch log group OK: $logGroup"

Write-Host "All smoke checks passed."
```

### download_cloudwatch_logs.ps1

```powershell
param(
  [string]$LogGroup = (terraform -chdir=infra output -raw log_group_name),
  [string]$Region   = $env:AWS_DEFAULT_REGION ?? "us-east-1",
  [string]$OutDir   = "logs"
)

New-Item -ItemType Directory -Force -Path $OutDir | Out-Null
$streams = aws logs describe-log-streams --log-group-name $LogGroup --region $Region |
  ConvertFrom-Json

foreach ($s in $streams.logStreams) {
  $safe = $s.logStreamName -replace "[/:]", "_"
  aws logs get-log-events `
    --log-group-name $LogGroup `
    --log-stream-name $s.logStreamName `
    --region $Region |
    ConvertFrom-Json |
    ConvertTo-Json -Depth 10 |
    Out-File "$OutDir/$safe.json"
  Write-Host "Downloaded: $safe.json"
}
```

### gitbash/precheck.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

PROJECT=${TF_VAR_project_name:-data-platform}
ENV=${TF_VAR_environment:-dev}
REGION=${AWS_DEFAULT_REGION:-us-east-1}
PREFIX="${PROJECT,,}-${ENV,,}"

OUTPUTS=$(terraform -chdir=infra output -json)
BUCKET=$(echo "$OUTPUTS" | jq -r '.artifact_bucket_name.value')
LOG_GROUP=$(echo "$OUTPUTS" | jq -r '.log_group_name.value')

echo "Checking S3 bucket: $BUCKET"
aws s3 ls "s3://$BUCKET" > /dev/null

echo "Checking CloudWatch log group: $LOG_GROUP"
aws logs describe-log-groups --log-group-name-prefix "$LOG_GROUP" --region "$REGION" > /dev/null

echo "All precheck validations passed."
```

## Validation table (SPEC-009 §4.2)

| Resource       | Script                  | Validates                        |
|----------------|-------------------------|----------------------------------|
| S3             | `smoke_resources.ps1`   | bucket exists + accessible       |
| IAM            | `validate_iam.ps1`      | role + trust policy + policies   |
| CloudWatch     | `smoke_resources.ps1`   | log group exists                 |
| Tags           | `validate_tags.ps1`     | 5 mandatory tags present         |
| Budget         | `validate_budget.ps1`   | at least one budget configured   |

## Rules

- Generate these scripts whenever AWS resources are deployed in a host repository
- Scripts must read values from `terraform output` — never hardcode ARNs or names
- All scripts must accept parameters with sensible defaults from env vars
- Provide both PowerShell (`.ps1`) and bash (`.sh`) equivalents

## Avoid

- Hardcoding resource names or ARNs
- Scripts that require AWS Console interaction
- Missing the `gitbash/` equivalent for CI/Linux environments
