# Step Functions Pattern

## When to use

- Orchestrating workflows
- Multi-step pipelines
- Error handling and retries

## Core idea

Define workflows as state machines.

## Patterns

- Sequential steps
- Parallel execution
- Retry with backoff
- Conditional branching

## Best practices

- Keep states simple
- Handle failures explicitly
- Use for orchestration, not heavy compute

## Common use cases

- ETL pipelines
- Batch workflows
- Data processing pipelines

## Avoid

- Embedding business logic
