# EventBridge Pattern

## When to use

- Event-driven architecture
- Decoupling services
- Scheduling jobs

## Core idea

Use events to trigger workflows across services.

## Patterns

- Event routing
- Scheduled triggers (cron)
- Cross-service integration

## Best practices

- Use clear event schemas
- Avoid tight coupling
- Use rules for filtering

## Common use cases

- Trigger Glue jobs
- Trigger Lambda functions
- Schedule pipelines

## Avoid

- Using as message queue
